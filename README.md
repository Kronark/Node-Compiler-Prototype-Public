# Node Compiler Prototype
The official public repository for the Kronark node compiler. Due to recent developments in the LLM-based coding space, namely reverse engineering and clean-room reimplementations, open-source access to the node compiler source code will be halted until further notice. This repository will instead act as a hosting platform to download builds of the prototype. This decision has been made due to the nature of the project, which is that of an entirely novel software ecosystem. We need to avoid fragmenting the community around this approach early on - avoid file format drift and implementation branching. A robust ecosystem can only develop when the community surrounding it is pulling on the same thread, not on *n* different ones. LLMs have made it all too easy to reverse engineer binaries or circumvent licensing through clean-room loopholes. Therefore, we are forced to keep prototype implementation specifics close to the chest for the time being.
